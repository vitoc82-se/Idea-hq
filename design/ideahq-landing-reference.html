The AI can read your code. It can't write it.

Every build runs in your own GitHub, in two separate steps. The one with your key can't write. The one that writes never sees your key.

STEP 1 · THE AI Reads your repo, writes a patch has your key · read-only · can't open .env files
patch
STEP 2 · THE BUILDER Applies it, runs your tests can write a branch · never sees your key
PR
STEP 3 · YOU Read it. Merge it. Or don't. Tests must pass first. Any merge can be undone with one button.
  • Your code stays on GitHub. Idea HQ never hosts or copies your app.
  • Your key stays in GitHub. We check it once, save it as a repo secret, and forget it.

Things people ask

Do I need to know how to code?

No. You need a GitHub account and an Anthropic or OpenAI API key. Setup takes about 10 minutes and the app walks you through it.

How is this different from Lovable?

Lovable is great for starting an app. Idea HQ is for after: your app lives on GitHub, and every change is a pull request you approve.

And from Claude Code?

Same models, different job. Claude Code is a developer tool for the terminal. Idea HQ is a notebook for ideas and bugs, with a review step anyone can use.

Can the AI break my app?

Only if you merge something broken. Every change is a proposal, your tests must pass, and any merge can be undone.

Can I use ChatGPT instead?

Yes. Pick OpenAI in setup and add an OpenAI API key (a ChatGPT subscription doesn't include one). Gemini support is coming soon.
